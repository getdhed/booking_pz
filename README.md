# ПЗ №1: Middleware, EJS и PostgreSQL

Небольшое Express-приложение по теме бронирования переговорных комнат.
Страницы формируются через EJS, запросы логируются в консоль и `logs.txt`, а комнаты хранятся в PostgreSQL через Sequelize.

## Что нужно установить

- Node.js
- PostgreSQL

## Подготовка базы данных

1. Создайте пустую базу PostgreSQL, например:

```sql
CREATE DATABASE booking_pz
```

2. Скопируйте `.env.example` в `.env` и укажите свои параметры PostgreSQL:

```env
DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_NAME=booking_system
DB_HOST=127.0.0.1
DB_PORT=5432
PORT=3000
```

Отдельно создавать таблицу не требуется. При запуске `sequelize.sync()` автоматически создаст таблицу `Rooms`, если её ещё нет.
Если таблица пустая, приложение один раз добавит три демонстрационные комнаты.

## Запуск

```bash
npm install
npm start
```

После запуска:

- `http://localhost:3000/login` — учебная страница входа;
- `http://localhost:3000/?auth=1&role=user` — список комнат;
- `http://localhost:3000/?auth=1&role=admin` — список от имени администратора;
- `http://localhost:3000/add?auth=1&role=admin` — добавление комнаты;
- `http://localhost:3000/item/1?auth=1&role=user` — детальная страница;
- `http://localhost:3000/error?auth=1&role=admin` — учебная проверка 500.

## Структура БД

Используется одна таблица `Rooms`:

- `id` — идентификатор, автоинкремент;
- `name` — название;
- `roomNumber` — номер комнаты, уникальный;
- `location` — расположение;
- `floor` — этаж;
- `capacity` — вместимость;
- `description` — описание.

Все данные формы дополнительно валидируются на сервере перед записью в БД.

## Настройки валидации

Все изменяемые ограничения формы комнаты вынесены в:

`config/validationSettings.json`

Например, чтобы увеличить максимальную длину названия со 100 до 150 символов, достаточно изменить:

```json
"name": {
  "required": true,
  "minLength": 1,
  "maxLength": 150
}
```

После изменения настроек перезапустите Node.js-сервер. Эти значения используются одновременно серверной валидацией, HTML-формой и моделью Sequelize.
