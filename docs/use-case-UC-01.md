# UC-01 — Добавление переговорной комнаты

**Проект:** Booking PZ (веб-приложение на Express/EJS и PostgreSQL).
**Цель:** администратор добавляет новую комнату для отображения в общем списке.
**Действующее лицо:** администратор (учебный режим входа).
**Приоритет:** высокий.
**Триггер:** администратор открывает форму `GET /add?auth=1&role=admin` и нажимает «Добавить».

## Предусловия

1. Запущен Node.js-сервер и доступна PostgreSQL.
2. Администратор находится в учебном режиме: `auth=1&role=admin`.
3. Номер будущей комнаты ещё не занят другой записью в таблице Rooms.

> Важно: авторизация в данном учебном проекте имитируется параметрами URL, а не реальными логином и паролем. Это **не** защищённый механизм для боевой системы.

## Основной сценарий

1. Администратор открывает `/add?auth=1&role=admin`.
2. Система показывает форму «Добавить комнату».
3. Администратор заполняет обязательные поля: название, номер, расположение, этаж и вместимость; описание необязательно.
4. Администратор нажимает «Добавить».
5. Браузер отправляет `POST /add?auth=1&role=admin` в формате `application/x-www-form-urlencoded`.
6. Сервер проверяет доступ, типы, обязательность, длины и диапазоны полей.
7. Сервер создаёт комнату в PostgreSQL через Sequelize.
8. Сервер отвечает **HTTP 303 See Other** и перенаправляет на `/?auth=1&role=admin`.
9. Новая комната отображается в общем списке.

## Поля и ограничения

| Поле | Обязательное | Допустимые значения |
|---|---|---|
| `name` | Да | Текст 1–100 символов после `trim` |
| `roomNumber` | Да | Текст 1–20 символов, уникальный номер |
| `location` | Да | Текст 1–150 символов |
| `floor` | Да | Целое число от 1 до 100 |
| `capacity` | Да | Целое число от 1 до 1000 |
| `description` | Нет | Текст до 2000 символов |

Переносы CRLF в текстовых полях нормализуются к LF. Допустимые границы взяты из `config/validationSettings.json`.

## Альтернативные сценарии и исключения

- **A1 — необязательное описание отсутствует:** сервер сохраняет пустую строку.
- **E1 — нет учебной авторизации:** переход на `/login`, **HTTP 302**, запись не создаётся.
- **E2 — роль user вместо admin:** **HTTP 403 Forbidden**, запись не создаётся.
- **E3 — обязательное поле пустое/отсутствует:** **HTTP 400 Bad Request**, показываются ошибки, запись не создаётся.
- **E4 — длина, тип или числовой диапазон нарушены:** **HTTP 400 Bad Request**, запись не создаётся.
- **E5 — номер комнаты уже существует:** **HTTP 400 Bad Request**, сообщение о дубликате, запись не создаётся.
- **E6 — недоступна БД или иная необработанная ошибка:** общий обработчик ошибок, обычно **HTTP 500**, запись не считается успешно созданной.

## Постусловия

**Успех:** новая запись есть в `Rooms` и видна в списке. **Ошибка валидации/доступа:** новая запись не создаётся.
